Esta política explica quais dados o Equilibrium coleta, para quê, e quais direitos você tem sobre eles.

1. Quem coleta e trata seus dados

O Equilibrium ("nós") é o controlador dos dados pessoais tratados através do app, nos termos da Lei Geral de Proteção de Dados (LGPD).

2. Quais dados coletamos

  • Dados de cadastro: nome, apelido, e-mail, telefone (opcional), data de nascimento.
  • Dados de uso: frases curtidas, histórico de escolhas, preferências de notificação e aparência.
  • Dados técnicos: identificadores de notificação push do seu dispositivo.

3. Para que usamos seus dados

  • Fornecer o serviço: autenticação, personalização da saudação, notificações da sua frase do dia, histórico e resumos.
  • Melhorar as sugestões de frases ao longo do tempo, com base nas suas próprias escolhas.
  • Verificar que você tem 18 anos ou mais, idade mínima para usar o Equilibrium.

4. Com quem compartilhamos

Usamos provedores de infraestrutura (Google Firebase/Cloud, para hospedagem e autenticação; Expo, para entrega de notificações) que processam dados só para viabilizar o funcionamento do app, nunca para finalidade própria. Não vendemos nem compartilhamos seus dados com terceiros para fins de publicidade.

5. Por quanto tempo guardamos seus dados

Enquanto sua conta estiver ativa. Se você excluir sua conta, apagamos seus dados pessoais identificáveis (nome, apelido, e-mail, telefone, data de nascimento, credenciais). Suas frases curtidas ao longo do tempo são mantidas de forma anonimizada e agregada (sem qualquer vínculo com você) para continuar ajudando a melhorar as sugestões para outras pessoas.

6. Seus direitos

Você pode, a qualquer momento:

  • Acessar e corrigir seus dados pessoais (tela "Editar dados" no app).
  • Excluir sua conta (Configurações → Excluir conta, ou pela página de exclusão de conta).
  • Solicitar acesso completo aos seus dados, portabilidade, ou esclarecer dúvidas sobre este tratamento, escrevendo para contatoapp.equilibrium@gmail.com.

7. Encarregado de dados (DPO)

Para questões sobre proteção de dados, contate William Nunes Pinheiro em contatoapp.equilibrium@gmail.com.

8. Alterações a esta política

Podemos atualizar esta política; mudanças relevantes serão comunicadas dentro do app.
